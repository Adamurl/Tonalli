## Availability

Pages 138, 141, 174–176, 178, and 188 were absent from the supplied main-page photographs. The unknown word on page 155 and unreadable fine print on page 172 remain marked. Page 159 is inferred from its adjoining pages.

The trecena file preserves the surviving fragment of the eighteenth trecena on page 189; it does not reconstruct the absent seventeenth-trecena entry or the missing opening of the eighteenth.

All prose, quotations, tables, and captions are retained in the records. A source page can appear in two records when it contains the end of one entry and the start of another. Each passage belongs to one record. These files are prepared for website integration and are not connected to the frontend or database.
